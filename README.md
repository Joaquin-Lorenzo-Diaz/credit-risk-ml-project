# Credit Risk Modeling with Machine Learning

🇪🇸 [Leer en español](README.es.md)

End-to-end credit risk project applying Machine Learning.

**Dataset:** Lending Club (real US consumer loans, 2007-2018; 1.3M+ loans with a final outcome used for modeling)

## 🎯 Objective

Build a complete credit risk pipeline: from exploratory analysis to portfolio expected loss and stress testing, replicating the workflow of a real credit risk analyst.

## 📊 Key results

| Metric | Result |
|---|---|
| NPL ratio | 2.36% |
| AUC-ROC (PD model, XGBoost) | 0.7147 |
| Average LGD | 46.7% |
| Portfolio expected loss | 10.07% |
| Expected loss under stress (99th percentile, Monte Carlo, assumed macro sensitivity) | +70% vs. baseline |

## 🛠️ Tech stack

- **Python:** Pandas, NumPy, scikit-learn, XGBoost, Matplotlib
- **Automation:** REST APIs (requests), n8n
- **Version control:** Git/GitHub

## 📁 Project structure

```text
notebooks/
├── 01_eda_npl_vintage.ipynb     → EDA, NPL ratio, vintage analysis
├── 02_pd_model.ipynb            → Probability of Default model (XGBoost vs. Logistic Regression)
├── 03_lgd_model.ipynb           → Loss Given Default model
├── 04_expected_loss.ipynb       → Portfolio expected loss (PD × LGD × EAD)
├── 05_pd_model_improved.ipynb   → Feature engineering applied to the PD model
├── 06_stress_testing.ipynb      → Stress testing with Monte Carlo simulation
└── 07_api_consumption.ipynb     → API consumption (DolarAPI) and business rules

pd_model_xgb.pkl                 → Trained PD model (generated by notebook 02)
lgd_by_grade.json                → LGD by grade (generated by notebook 03)
fx_gap_monitor.py                → Automation script (API consumption + business rules)
```

## 🔑 Concepts applied

PD, LGD, EAD, Expected Loss, NPL, Vintage Analysis, Feature Engineering, AUC-ROC, Monte Carlo Simulation, Stress Testing, Process automation with APIs.

## ⚙️ How to reproduce

1. Clone the repository
2. Create and activate a virtual environment: `python -m venv venv`
3. Install the dependencies: `pip install pandas numpy scikit-learn xgboost matplotlib jupyter kaggle requests`
4. Download the dataset from [Lending Club on Kaggle](https://www.kaggle.com/datasets/wordsforthewise/lending-club) into a `data/` folder in the project root (the file used is `accepted_2007_to_2018Q4.csv.gz`). With the Kaggle CLI: `kaggle datasets download -d wordsforthewise/lending-club -p data`, then unzip it.
5. Run the notebooks in order (01 to 07). Notebook 02 saves the trained PD model (`pd_model_xgb.pkl`) and notebook 03 saves the LGD by grade (`lgd_by_grade.json`); notebooks 04 and 06 load both.
6. Optional: run `python fx_gap_monitor.py` for the standalone FX gap monitor.
